## 三角色与密钥的真实契约

`modelRoutes.main / image / vision` 独立保存 `accessProvider + modelId`；凭据按渠道存储和提交，同渠道多个角色共享 Key，MiniMax 中国/国际区域分别保存。没有新增三个会在提交时互相覆盖的角色 Key 字段。专业模式保留混合渠道；普通模式仍是明确的统一渠道操作。

本次任务是否需要某个角色继续由真实执行计划决定。即使某角色暂不调用，也可在它附近找到配置入口；校验和实际请求只要求本次调用渠道。观猹连接只满足观猹凭据，不能满足 Google。草稿里的模型、区域和 Key 状态一起更新，保存才应用，取消丢弃；仅浏览目录不改变已保存模型。

密码输入保持遮蔽，不记录明文密钥。手动 Key 保留在会话内存；现有可恢复任务的服务端加密保存机制继续沿用，完成即删、最长 7 天。模型与输出白名单偏好仍不包含 Key。

在 320px 原生模拟器中，通过真实页面提交函数、本地请求拦截核对：主模型 `gemini/gemini-3.8-flash`，图像 `tokendance/seedream-5.0-pro`，识图 `tokendance/qwen3.8-flash`；请求仅含 `gemini` 凭据渠道，参考选择为 `ref_251`。保存前缺少 Google Key 时按钮不可提交；取消输入不会改变已保存配置。没有调用真实付费模型。

## mini-status 404

本轮只读请求确认 `https://api.paperbanana.asia/api/auth/watcha/mini-status` 返回 HTTP 404、空响应体；Web 的 `/api/auth/watcha/status` 返回 `available: true`，但未提供小程序接续能力。仓库 `apps/auth-gateway/src/watcha-mini.js` 已有新接口；`SYNC.md` 顶部仍明确未完成 Gateway 补充部署。现象符合线上尚未提供小程序身份接续桥，尚未核对线上容器精确 SHA，不能据此认定部署完成。

影响是小程序的观猹身份登录/绑定接续不可用；已有图研邮箱登录和独立的 TokenDance 消费连接不因此失效。本轮客户端显示具体部署诊断及邮箱回退说明，保留真实404；没有隐藏日志、改成伪成功或把 Web 状态当作小程序支持。需要后端补部署与真机跨浏览器验收，不能靠 UI 修改关闭该门禁。
