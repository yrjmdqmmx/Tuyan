## 兼容和验证边界

Route v1 保持可选扩展、旧值约束及手动配置路径；浏览器/导入导出没有 Key、到期凭据或验证成功状态。小程序共享类型和生成物已合入源码，原生设置、真机、软键盘与微信发行仍按 SYNC 欠项管理。

此前本地验收 Core 1,089、Web 577、小程序 121、SG 111 项范围通过，详见[本地验收](../universal-api/2026-09-28/acceptance.md)。生产仅进行只读目录/健康/排行与浏览器配置检查，没有付费模型/Judge 调用、充值、真实登录/邮件回路、生产生成/故障恢复演练或微信上传/审核/发布。

Azure 必须补充实际资源域名的精确受控出口；没有泛域名放行。xAI 未确认的多图/输出参数、Azure 未确认的图像工具型号，以及其他未适配模型仍不自动启用。真实账户调用/权限/计费未验证。官方来源与核查日期见[审计](../universal-api/2026-09-28/sources.md)。

线上实际浏览器验收：桌面 1440px 与 390/320px，三角色 TokenDance 首次默认、通用 API 首位、Azure/Bedrock/OpenAI 混用、字段限制、密钥隔离、保存刷新、焦点/返回及草稿恢复通过；无控制台/页面错误。15 个线上 HTML/JS/CSS 资源与 Pages 发布产物逐字节一致。测试未发送通用 Key、地址检查、目录探测或付费请求，只读 modelRegistry/referenceLibrary。初次脚本误拦外部图片、Python 本机证书链问题及偶发 TLS 失败已分别用正常只读资源加载、保留 TLS 验证的系统 curl 有界重试纠正；未改变产品安全规则。详见[脱敏证据](2026-09-28-tuyan-v3.8.1-supplement.evidence.json)。
