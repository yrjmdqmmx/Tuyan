# 生成设置与模型目录选择

基线：`c05e340`。实现位于独立 `codex/settings-catalog-20260920` 分支；不改旧 Desktop checkout。生产发布状态在本文后续补充。

## 修复内容

- 原双列模式控件容纳三个选项，造成 2+1 换行；改为三行等宽、同高的选择卡片。原 `secondary-button` 没有基础样式定义，新增通用接入专用的完整控件样式与焦点、禁用、加载和状态反馈。
- 空模型 ID 使用中性引导；键入时不弹出能力错误，失焦或主动检查时才解释角色所需能力。官方能力匹配仍按协议、精确地址和准确 ID，独立于密钥。图像未配置时比例区域显示填写引导。
- 目录只检查连接，不要求先有模型、能力或图片限额；增加搜索、明确选择、手动输入与刷新。目录可见不等于配置校验或真实调用成功。刷新不会替换已选型号，目录不包含当前 ID 时保留并说明。
- 连接和密钥身份、递增请求序号共同阻止旧响应覆盖新配置，包括地址 A → B → A。目录及代理返回格式再次校验，HTTP 200 的 HTML/空对象不能冒充有效空目录。网络与服务错误使用安全中文文案。
- 严格公网 HTTPS/DNS 固定、密钥地址绑定、生成能力与预算、任务恢复及未知费用边界保留。新共享连接接口与小程序类型同步，无新增平台发布或数据库迁移。

协议、目录规则、分页/异常隔离边界及官方来源见 [目录适配说明](../universal-api/catalog-selection.md)。
