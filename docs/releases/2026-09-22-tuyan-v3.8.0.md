# Tuyan v3.8.0 发布

用户在本地验收后明确授权“上线”。Tuyan v3.8.0 的 Web / Core 功能于北京时间 **2026-09-22 23:49** 完成发布，功能提交为 `d40f1a8c2be6e315ee00b45cceca1a832ca4521d`，PR [#228](https://github.com/yrjmdqmmx/Tuyan/pull/228)。公开版本条目在实际 Web / Core 部署及只读验收之后回填；记录 PR 仅更新 Web 日志、翻译、测试及维护资料，不改变后端运行版本。

## 发布范围

- 共享顶部导航：品牌、页面、工具与生态、支持与交流、语言与账户分组。工作台、排行榜、openacad 顺序和选中状态保持一致；手机“更多”使用相同分类，语言按钮在顶部保持可见。
- 三角色思考设置移到各自模型下方，仅展示精确渠道／型号／协议已支持的强度、开关或预算；不支持的控件隐藏，帮助收起。“默认”不显式发送参数，原有独立保存、请求校验、费用与任务恢复保持兼容。
- 官方渠道目录 v24：商汤 7、阶跃星辰 7、百度千帆 36、讯飞星辰 MaaS 32、美团 LongCat 1 个型号，共 83 个；主模型、视觉、生图和编辑按具体接口适配。新增 Grok 4.7 及两项多智能体身份；MiniMax 渠道显示为稀宇科技。完整能力、价格、地区、准入及未接入原因见[官方渠道审计](../channel-audit/2026-09-22-official-expansion/README.md)。
- 工作台／排行榜／更新日志共享中英文偏好。日志按独立产品版本和生态事件整理，默认汇总，同日分组、日期倒序，仅显示已发布内容。
- Tuyan 3.7.1 之后的工作台更新统一为 3.8.0；保留其前版本与 PaperBanana 历史品牌。Benchmark 和 OpenAcad 独立编号；小程序、Skill、MCP、平台上架属于生态事件。独立论文画布 PR #225 未合并或部署。
- 修复仅文本高级渠道返回普通模式、未填完通用 API 配置时的页面空白，保留完整预设及可继续编辑的草稿。
