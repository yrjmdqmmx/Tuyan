# Tuyan v3.8.1 本地开发交付（待发布）

状态：**unreleased / 待发布**。工作分支 `codex/tuyan-v3.8.1`；基于最新主分支 `e2b70cfc849cc4de323df63827262b877083d1c0`，交付前只读复查远端主分支仍是该提交。代码位于独立工作树 `tuyan-v381-20260927`；Desktop 原检出和独立小程序工作树未修改。本轮无 push、生产部署、充值、真实模型调用或微信上传/审核/发布。

## 实际修改

- Web 仅保留普通与专业模式；通用 API 进入专业模式三个角色的渠道选择。每个角色独立选择预设或通用接入，继续使用原有路由、协议与任务链。
- 保留旧 `tuyan.universal-api.v1` 的地址、模型 ID、协议、认证方式、兼容变体、目录规则、能力限额和尺寸映射。旧非空角色草稿恢复到专业模式；新 `tuyan.model-routing.v1` 只记录模式和角色选择。密钥沿用页面内存与接入绑定，不迁移到持久存储。思考参数继续由原有独立身份偏好保存。
- 首次进入专业模式承接普通预设，后续来回切换保留专业组合。通用角色配置就地编辑，保存入口只出现一次；凭据、参数和图片能力按具体角色校验。改变地址/协议/认证后清除该角色的旧绑定密钥；仅切换渠道不会清除其草稿或密钥。
- 生成、精修及优化输入只携带所需角色凭据；通用主模型缺有效绑定密钥时在本地拦截优化输入。未知协议能力不因目录可见而获得授权，不支持的协议能力不能新勾选，历史不兼容声明保留供修正。
- 目录 v26 新增百灵六个准确文本 ID（其中一个支持视觉）和 LongCat-2.5-Preview 文本。保持 LongCat-2.0 默认和历史配置。同步准入白名单、三角色路由、思考参数、Base64 图像、格式/字节限制、公开价格与 usage 记录，以及现有加密恢复/收费请求防重逻辑。

逐型号 API、鉴权、地域/账户限制、上下文、图片限额与价格见 [官方来源审计](../channel-audit/2026-09-27-v381/README.md)。所有新模型当前都是“目录已收录、代码已适配、真实调用未验证”。
