# 参考图预算与中文错误体验发布（2026-09-16）

Web 和 Core 已发布 [PR #200](https://github.com/yrjmdqmmx/Tuyan/pull/200)，版本 `2295cc15d9937c0cb0b3c9adebd911aca06b42c0`。香港部署与 GitHub Pages 均成功；生产审批沿用正常 required-reviewer 流程，没有绕过门禁。
