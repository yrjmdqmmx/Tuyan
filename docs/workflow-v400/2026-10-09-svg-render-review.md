## 最终采用的轮数定义

用户后续澄清优先于最初“预算结束保留已检查版本”的要求：**一轮包含检查、主模型完整优化方案，以及必要时重新生成。**

设置 1 轮：主模型规划 → 生成 SVG v1 → 实际渲染 v1 → 检查画面和完整代码 → 主模型决定并制定完整方案 → 有问题则生成 v2，交付 v2 并标为“已修改，尚未复审”。如果 v1 不需要修改，交付已检查通过的 v1。不会因用完检查次数而跳过本轮必要修订，也不会隐藏追加 v2 的检查调用。

R 轮最多检查 R 次、修订生成 R 次，另有初次生成；提前通过即可结束。辅助视觉每轮增加一次观察调用。基础 diagram 和 0 轮显示“未评审”。修改生成失败时保留最近成功 SVG；已经检查仍有问题、检查失败、检查通过分别记录。网络结果不明仍触发原有停止/恢复屏障，但先将已成功 SVG 保存到结果列表。

## 文件和证据绑定

每版保存独立 SVG、真实 PNG 和送审图片。`review` 扩展包含 `deliveredVersion/deliveredSvgHash`、`reviewedVersion/reviewedSvgHash` 和 `history`；每条历史记录 round/version、SVG SHA-256、原始渲染 PNG SHA-256、实际送审图片 SHA-256、状态和结论。送审副本可能依照所选模型图片预算等比处理，其摘要与原始渲染摘要分开保存。修改版不继承旧版结论。

新的 `workflowContractVersion=2` 防止新 Web 把旧后端的文字方案检查当作实际 SVG 评审。保留旧 `text_reviewed` 的历史说明；新的 SVG 使用 `visual_code`。结果展示明确区分未评审、通过、已修改尚未复审、评审失败、已检查仍有问题。

- 初次生成使用 `/images/generations`，显式保持 `model`，实际 PNG/JPEG/WebP 通过 `style_reference_urls`；最多 10 张。风格参考不保证内容或局部结构锁定，服务器可能另收风格创建费用。[官方生成接口](https://www.recraft.ai/docs/api-reference/endpoints)

- V2/V3 提示词限制 1000 字符，V4/V4.1 为 10000。完整上下文超限明确拒绝，不截断。图片本地采取保守十进制 20 MB 单图、64 MB 合计、256～4096 边长和 16 MP 限额；不符合即拒绝。V2 修订时为上一版预留一张参考额度。[官方限制](https://www.recraft.ai/docs/api-reference/appendix)

## 渲染支持与边界

使用固定版本 resvg WASM、严格 XML 校验和许可完整的 Noto Sans/CJK/Math 字体。图片由交付源码实际生成；字体缺失/缺字、无效 XML、活动内容、外链和嵌入位图明确失败。最长边 4096、8 MP、源码 5 MiB；普通生成提示按最长边 1600 生成比例正确的画布，避免 1:4 强制要求 6400 高度。

为控制中间画布和引用展开成本，限制复杂合成、滤镜、蒙版、pattern、非平凡透明度分组与过多剪裁；不静默移除这些视觉效果。每个实例的 WASM 线性内存由虚拟机硬性限制为 256 MiB，另有并发、展开量和执行时间限制；这不是总进程 RSS 上限，生产容器仍需操作系统层的内存隔离。固定 WASM 校验后仅修改内存中的 memory section，磁盘依赖和 SVG 不变。详情见 `apps/paperbanana-api/assets/svg-review/README.md`。这意味着部分合法但超出安全子集的外部 SVG 会明确失败。仅固定 Regular 字体，不承诺任意客户端的同字体排版；字体版本和替代提示作为证据保存。

## 本地验证证据

`svg-review-evidence/` 为真实 Core/Gateway 加模拟模型的请求与输出留档。图片输入在 JSON 中记录实际字节数和 SHA-256，避免大段 base64；SVG/PNG 文件另存，可复核对应摘要。全部使用合成测试数据，不代表真实科研图质量。

- `ordinary-one-round-revision/`：请求顺序 plan → SVG v1 → review v1 → SVG v2，无终审；v2 是交付版、v1 是已检查版。
- `assistant-two-rounds/`：两版不同实际渲染图送给观察模型；主模型收到完整各版代码和报告，v2 检查通过后交付。
- `recraft-reference-revision/`：完整上下文、真实图库 style_reference_urls、上一版实际 PNG 的 image_url、相同模型和最后未复审状态。
- `basic-library-direct/` 与 `basic-library-assistant/`：真实图库像素、标题和说明进入正确角色的请求。
- 补充反例：0/1/2/5 轮预算、检查输出空/缺字段/版本错误/矛盾判断、重生成拒绝/网络结果不明、缺视觉能力、超长上下文、未知型号、图片数量/尺寸、xlink、1:4、未使用视觉配置和认证伪造，以及渲染资源限制。
