| 项目 | 规则 |
|---|---|
| 商品 | Plus 只有一个：39 元 / 日历月，每个购买周期 2000 积分 |
| 模式与格式 | 快速、均衡、极致是同一套餐的模式；PNG 与 SVG 共用余额 |
| 周期 | 使用支付平台返回的起止时间；到期未用积分失效，不结转 |

| 退款金额 | 未用积分 / 2000 × 39 元，整数分四舍五入；1000 积分对应 19.50 元 |

全额退款时支付手续费是否返还尚不明确；若不返还，即使模型费用为零，单笔退款仍可能产生手续费损失，不能承诺每笔退款交易都不亏。

图片调用除了 token 之外，还需计入已确认的输入图、输出图及计量档位。没有正式计价版本时不开放收费执行。此前 1500/2000 积分成本及单次次数均为研究测算，不是正式扣分承诺；模拟表中的 60、80、120 等数值只用来检验账本。

## 责任与接口

依据：[爱猹收 agent.md](https://pay.watcha.cn/agent.md)，文档版本 2026-10-28，2026-10-31 核查。

新增 `/api/plus`：`GET catalog/account`，`POST membership/check/quote/jobs/refund/request`，`GET jobs/:key`，`POST jobs/:key/cancel`。除默认关闭检查外，要求有效登录身份、匹配的 `X-Workspace-Account`、合法来源及非维护状态。不会接受客户端声称的消费金额、支付成功或退款凭证。写操作每个账号每分钟最多 30 次；任务并发默认 1。账户响应的 `lockedCredits` 显示权益异常/退款处理中保留的余额，不计入可用额度。

账本按环境、应用、权益、用户与周期起始时间分区。一个周期只发一次；同一任务键只预留和提交一次。提交超时保留原键与预留，不自动换键、换供应商或重发。结果查询只用服务端记录的原任务 ID。到期禁止新任务，原任务可以继续核对；旧周期释放不会转入新周期。退款后迟到的 granted 查询不能重新发放或恢复权益。即使新周期预留为 0，只要上一周期仍有待核对任务，也不能先申请退款。
