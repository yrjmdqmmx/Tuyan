## 发现与修复

1. 流式用量未完整读取：增加 include_usage，接收 usage-only 最后一帧，截断/过滤失败也先记录回执；同一累计回执只计一次。第一笔无用量响应保留上限 0.054428 元。
2. 结构化规划/评审输出不完整：按阶段启用百炼支持的 JSON Schema；多模态遵循官方退回 json_object 的限制，不降低本地评审标准。早期快速 PNG 的两候选虽出图，但评审未通过。
3. 修改原图 URL 无法被供应商访问：Qwen Image 改为校验后内联原始字节；一次 HTTP 400 无计费证据，仍保留 0.52 元上限，不直接判定免费。
4. 累计保守预留没有按用量释放：原子释放差额、持久结算标记、崩溃恢复及并发验证已补齐；未知请求仍占上限。极致 SVG 早期因此停止，后续极致 SVG 修改完整成功。
5. PNG 精修缺少输出格式上下文：按精修动作确定 PNG 预算；上传原图也强制独立结果评审。快速修改在模型调用前被拦截，修复后均衡及极致修改实测通过。
6. 文本 max_tokens 与 thinking_budget 分开计入费用上界；不把思考预算错误地挤占可见输出额度。

## 验证边界

最后 4 个真实修改任务均成功且评审通过。生成任务若最后一次修订没有再评审，继续标记 modified_unreviewed，不宣称通过。早期失败路径修复有本地回归，但快速 PNG 生成/修改没有修复后的再次真实验收；不会突破 12 次尝试自行补测。

公开费率、用量回执和供应商已结算账单是三个不同证据层。正式积分费率、输入/输出边界和任务预留上限仍须校准；配置模板保持 validated=false。生产模型和真实收款开关保持关闭。
