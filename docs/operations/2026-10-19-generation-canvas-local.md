## 本轮修正

用户指出原侧栏与上下状态栏缩小了实际图片区域。本轮移除这些占位区域，改为现有执行状态行的“阶段记录”入口和绝对定位的浮层。默认收起；展开、关闭或查看长记录均不改变画布布局。点击外部或 Escape 可关闭，按钮关闭及 Escape 返回入口焦点。

- 过程图复用正式图片的 `FigureViewport` 适应、缩放逻辑，不引入额外内边距或最小高度。打开记录不会替换已选成图，也不会卸载 SVG 编辑器、丢失未保存编辑。
- 复用原有每 5 秒查询；阶段正文、建议、错误和附件只保留在当前账号的临时执行状态。按 taskId / runId 隔离，完成后释放，不进入工作区同步和正式版本。长期运行保留最早的规划记录。
- 规划、风格设计、评审等阶段可分别展开：文本直接阅读，结构化评审展示结论、问题、建议、依据，完整 JSON 可在“原始记录”中查看。没有详细内容时明确提示。
- 不猜测当前模型内部进程。展示已返回记录、已用时间、等待下一阶段、渠道等待或更新延迟；只有 `render` 阶段图片可作为画布过程图，标明“尚未交付”。完成执行的服务记录仍可从原有“执行详情”查看。
- 纯 Web 展示改动，无后端或共享契约变化。
