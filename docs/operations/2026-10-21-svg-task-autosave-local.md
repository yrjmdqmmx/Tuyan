# SVG 原任务自动保存（本地验收）

正式工作树：`/Users/a1-6/.codex/worktrees/tuyan-multitab-release-20261019/paperbanana（tuyan）`。
本轮仅调整 Web；保留已有账户、移动布局、图标、头像、欢迎动画，以及其他会话正在进行的后端改动。未部署，未调用模型，未操作生产任务或图片。

## 行为

- 去除默认工作区的“浏览器手工稿”导航、搜索结果和页面路由，以及编辑器里的“保存为新版本”按钮。
- SVG 修改即时写入现有本机恢复日志；停止操作约 900 ms 后，沿用 `SAVE_SVG` 为原任务追加不可变编辑版本，并由现有 WorkspaceSyncController 上传结果和同步账号。
- 连续操作合并为一次保存；未修改的画布不创建版本。保存中继续编辑，后续修改进入下一次保存，画布、选中状态与撤销记录不因自动保存重建。
- 离开编辑器、页面进入后台、提交生成和主动退出登录时尝试完成待保存修改。保存错误不假报成功，可重试和导出；只有现有同步控制器确认 `synced` 才显示已同步账号。
- 自动保存后记住该任务的最新版本，不抢占其他任务或创作路径，也不覆盖用户明确切换到的历史版本。回到原任务继续编辑，原始 SVG、原提示词和历史版本保留。
- 空白画布同样在当前任务保存，无需调用模型。

## 备份和历史数据

- 新自动保存备份包含本机恢复所需的原版本与待提交版本标识；处理中断后可在原任务继续。服务端 API 和任务记录契约未扩展。
- 旧手工备份不会静默覆盖原图；能通过当前任务和候选版本确认关联的，提供任务内恢复入口。
- 旧工作台使用服务器 job ID 和候选 index 的备份，仅在所选历史版本具有相同服务、账号、job ID 和候选 index 时提供恢复。恢复追加到原任务，旧工作台备份原字节保留。
- 用户不恢复旧备份而开始新的编辑时，新的恢复记录使用独立本机键，保留旧记录。
- 无法可靠关联原任务或候选的旧记录不猜测归属、不创建替代任务、不删除。旧恢复工具代码保留，但不再作为常用页面入口。
- 本轮没有盘点或迁移生产浏览器数据。若历史任务已缺失，遗留备份需另行确认归属，不能承诺自动恢复到不存在的任务。
- 账号图片库继续执行既有大小、期限和归属规则。自动保存沿用不可变版本，因此不同内容的检查点仍占用实际存储；未新增版本压缩或合并的服务端策略。
- 使用统计仍从服务器生成任务交付记录读取；没有把手工自动保存版本数或当前图片库存量用作累计生成量。
