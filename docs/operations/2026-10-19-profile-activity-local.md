## 功能

- 上传 PNG / JPEG / WebP 静态头像，最大 2 MiB、最大 1600 万像素，服务端解码、自动旋转、居中裁成 256×256 WebP，去掉原文件元数据。输出上限 64 KB；存入已有私有用户 `image` 字段，不提供可枚举的公共图片地址。个人页与侧边栏刷新同一账号身份，支持恢复默认。
- 换邮箱验证当前邮箱与新邮箱的两个独立 6 位验证码。验证码绑定账号、当前会话和不可复用申请 ID；数据库只存 HMAC 摘要，10 分钟过期、最多 5 次校验。重复发起替换旧申请，发送任一邮件失败则申请作废。邮箱唯一索引处理并发占用；生命周期事务覆盖邮箱更新、凭证清理及所有旧会话撤销。
- 前端先保存草稿，再提交邮箱确认；成功后打开登录面板。任务、模型连接以不变的账号 ID 关联，不迁移到另一个账号。未验证完成不改变邮箱。旧邮箱在并发重置密码请求中不应收到新账号状态的有效重置证明，发送钩子检查最新身份后才投递。
- 绘制活动：按北京时间，最终交付 PNG / SVG 的候选张数；AI 精修独立计数。单次 3 候选记 3 张，内部评审重画、手工编辑、下载 / 导出不计，失败请求不计；部分失败的任务只计有成功候选证明的已交付图。任务与候选去重后汇总每天计数。
- 总计与单日峰值覆盖账号仍可用的服务器记录；最长连续天数跨年、跨闰日计算；今天没有绘制但昨天有绘制时延续当前连续记录，否则中断为 0。
- 热力图显示近 12 个月或所选年份，支持鼠标、触摸点击及方向键查看日期；每天、每周、累计总量均使用七行圆角方格：每天按颜色表示张数，每周按周汇总、累计按周末总量从下往上填充。月份在图下方，悬停 / 聚焦显示黑色圆角提示框，点击支持触摸查看，Escape、离开或滚动关闭。加载失败显示错误与重试，不把失败显示为无活动。

## 历史数据边界

统计读取 Core 中持久化的最终结果，不扫描浏览器缓存、内部过程图或生成提示词。以完成时间归档；无完成时间的旧记录用创建日期，并返回 `estimatedDateImages`，没有有效日期的图返回 `undatedImages` 并排除。接口只投影结果格式、候选身份、必要时间与成功状态，不返回提示词、密钥、过程日志或图片字节。已删除及从未上传的本机结果无法追溯。根据用户的界面精简要求，活动区不再常驻显示统计口径 / 数据范围说明、选中日期底栏和“少 / 多”图例；数据契约与实际口径保持不变，本节保留边界记录。

## API 与生命周期

- Gateway `/api/account/profile`：所有请求需要现有会话和匹配的 `X-Workspace-Account`；写请求需要允许的 Origin 和 JSON，维护模式下禁止写入。
- `POST /avatar`：`{base64}`，`null` 恢复默认。图片入口独立限流，不能通过 Better Auth `update-user.image` 绕过。
- `POST /email/start`：`{newEmail}` → `{requestId,expiresInSeconds}`。邮件仅经现有 DirectMail 通道；未配置投递时拒绝操作。
- `POST /email/confirm`：`{requestId,oldCode,newCode}` → `{ok:true,signInRequired:true}`。删除所有该账号会话，清理旧验证与观猹待确认材料，不删除观猹正式账号绑定或模型连接。
- `GET /activity`：`contractVersion:1`、`timeZone`、`today`、`days[{date,count}]`、四项指标及历史质量说明。内部 `userDrawingActivity` 从受保护的 Gateway 认证头取账号，不信任浏览器输入的用户 ID。
- 新集合 `accountEmailChanges` 的 TTL 索引随 Auth 初始化创建，并进入统一账号删除清单；头像随 `user` 文档删除。
