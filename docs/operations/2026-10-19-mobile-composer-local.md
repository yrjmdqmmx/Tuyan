# 移动端输入区与任务导航本地调整

范围：Web，基于当前 `codex/hangzhou-production` 工作树的既有未发布修改继续调整。未推送、未部署、未调用真实模型。纯前端 UI 与本地 reducer 调整，无后端或跨端契约变化。

- 窄屏输入区分为两种样式：收起时为较窄的单行胶囊，只显示上传加号与发送；聚焦后加宽展开，上方输入、下方工具栏，显示普通/专业滑块、模型配置、绘图设置及可用时的优化输入。图标保留中文可访问名称与悬停提示。
- 输入获得焦点时，左右各增加 20 px 宽度，文本区从最少 44 px 增至 88 px，长文最多 136 px 后滚动。工具按钮按下时保留输入焦点直至 click，避免键盘收起使按钮跳动、首次点击失效。在工具栏内使用键盘导航及打开设置弹窗时保留展开状态；离开输入区后收起，完整草稿和已选模式保留。
- 使用原生 textarea 唤起手机系统键盘；VisualViewport 在键盘覆盖布局视口时调整工作区可见高度，处理收起、失焦与缩放。桌面 iframe 预览另有明确标注的键盘占位演示，不进入产品代码。
- 移动端配置摘要置于输入框上方，保留附件用途、补传原件、精修目标及提交校验。
- 移除“复用上次要求”入口及 `REUSE` 分支；取消“本任务已有执行，完成后可提交”常驻提示。进行中的任务仍阻止重复提交，成功或失败结束后可提交新的有效草稿。
- 窄屏任务导航改为左侧抽屉：品牌及搜索在顶部，置顶/最近任务区滚动，新建任务及设置入口在底部。主页面平移显示一部分，宽度不变；保留焦点约束、Escape、账户菜单与草稿。
