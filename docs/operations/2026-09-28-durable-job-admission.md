## 根因与行为

原流程在 Mongo 写入 `paperbanana_jobs` 后即返回任务 ID，恢复快照却在 `ProviderWorkflow.run()` 获得执行槽时才写入。内存排队期间进程退出，会留下没有原参数/凭据快照的任务。关闭浏览器不会停止后端，不是该故障的触发条件。

新建的已登录生成/精修任务依次完成：

1. 预留有界准入容量，校验角色、参数、账号生命周期及输入。
2. 写任务记录；精修先将原图、辅助图和遮罩冻结为该任务的 OSS 对象。
3. 写入加密恢复快照，包含原 ID、执行类型、角色路由、参数/思考快照、输入路径及必需凭据；明确使用 Mongo `w: majority, j: true, wtimeoutMS: 10000`。
4. 再检查账号生命周期并提交内存队列；只有成功后才返回业务成功码和任务 ID。

快照写入或准入提交失败：不运行模型，业务响应失败、释放容量，并尽力将任务记为 `JOB_ADMISSION_NOT_STARTED`、`not_sent/not_called`。清理只匹配本实例尚未执行的快照，不删除已转交的执行记录。数据库故障导致写入结果不明时不发起调用，恢复后先查原任务记录。

| 情形 | 状态与处理 |
|---|---|
| 关闭页面后重新进入 | 原任务继续在服务端执行；同账号从任务记录查看进度，不会因此提交新任务。 |
| 已确认排队，执行前进程退出 | 启动仍标记中断任务为 `failed`；读取任务时协调为 `recovery.canResume=true`，说明“原任务尚未开始”。用户点击“继续原任务”，沿用同一 ID。 |
| 任务已完成部分步骤且安全可恢复 | 复用已有模型结果、原参数与输入；只有明确恢复后才继续。 |
| 已有 running/unknown 调用，结果未确认 | `canResume=false`、需核对记录；不自动重发，不因为队列记录看似未启动而推断未调用。 |
| 快照过期、丢失或旧执行版本不兼容 | 不重新创建一个付费执行来替代原快照；需核对已有结果。恢复资料原有 7 天 TTL 不变。 |

这是“原任务可恢复”，不是无人值守自动重试。重启后的用户可见主状态仍为“未完成/失败”，恢复入口解释可继续的原因。`RUNTIME_INTERRUPTED_REVIEW` 替代笼统的 `RUNTIME_RESTARTED_RETRY`，`retryable=false` 不再建议重新提交。小程序仍兼容读取旧错误码，并使用相同的安全提示。

## 保留的约束

- 不增加明文密钥或浏览器凭据持久化。服务端复用既有密钥加密服务；TokenDance 快照只保留连接依赖，恢复时重新读取该用户的当前授权。其他渠道密钥仍隔离在加密快照中，公开任务记录无密钥。
- `admissionVersion: 1` 仅为内部执行快照标记；请求体、Route v1、步骤指纹和原有执行版本保持。历史任务没有该标记时仍走已有恢复路径，不能补造过去未保存的数据。
- 重复恢复由 Mongo 条件更新竞争，只有一个请求入队；旧实例的内存条目不能领取新实例的快照，也不能把新实例任务覆盖为失败。
- HTTPS/DNS/SSRF、图片/编码体预算、并发队列上限、已完成结果复用和未知结果不重发规则保持。
- 新的持久化承诺覆盖已登录任务。历史未保存快照、匿名任务没有账号找回能力、Mongo/OSS 数据丢失或加密密钥丢失，不属于本次能够补救的情形。
- 架构仍为既有单 Core + Mongo 单成员副本集；本次没有引入跨实例调度。单成员 `majority+journal` 不等于多节点高可用或备份。发布/回滚仍需按现有流程排空并停止旧实例，旧后端不提供新增的准入持久化保证。

## 实际代码与跨端

- `apps/paperbanana-api/src/provider-workflow.ts`：准入快照、受限清理、实例归属检查、未开始任务的恢复/费用状态、过期恢复资格检查。
- `apps/paperbanana-api/runtime/handler.ts`：生成与精修等待快照后才确认接收，失败释放队列；被撤销的预留不能确认成功；失去快照归属的旧条目不覆盖任务。
- `apps/paperbanana-api/src/mongo-adapter.ts`：启动中断提示，不承诺所有收费请求可重试。
- `apps/web/src/components/TokenDancePanel.jsx`：尚未开始任务使用“原任务已保存 / 继续原任务”，隐藏无关的余额、权限处理提示；查看历史不自动调用恢复接口。
- 小程序 `business-errors.ts/js`：新旧重启错误码指引同步。没有修改独立小程序工作树或微信副本，没有宣称原生界面或真机验收完成。
