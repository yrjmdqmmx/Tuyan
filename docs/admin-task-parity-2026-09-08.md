# 站长近期任务信息补齐 · 2026-09-08

新版运营后台的任务列表与详情遗漏了旧版任务卡片中的生成配置和图片下载。此次按旧版截图与 `JobTable.jsx`、任务持久化字段及 `publicJob` 交叉核对，补回已保存信息，保留服务端分页与新后台的运营操作。

## 改动

- 列表直接展示来源、模式、类别、格式、检索、阶段数、参考图数量，保留归属、状态、主/图像模型和时间耗时。
- “展开任务内容”按需请求单条详情，展示全部配置、论文方法内容、目标图注、负向提示词、结果图、参考图、失败原因、阶段和日志。从展开内容进入详情再返回，保留展开状态、列表筛选与滚动位置。
- 详情复用同一任务内容组件，恢复参考图识别模型、参考图实际处理方式、评审模式；同时显示比例、尺寸、候选数、最大评审轮数与阶段评审建议、耗时。区分已配置识图模型与实际使用情况，保留数值 0，缺失历史字段明确为“未记录”。
- 复用原单图与 ZIP 下载实现：结果、参考图与阶段图支持下载/打开；ZIP 包含各类图片及已脱敏任务信息，部分图片下载失败时保留原有明确反馈。
- Core 为原有站长接口增加白名单配置字段与数组计数。列表不返回完整输入、图片或阶段载荷；详情沿用图片签名刷新。权限、账号生命周期和运营跟进 CAS / 审计规则不变。
