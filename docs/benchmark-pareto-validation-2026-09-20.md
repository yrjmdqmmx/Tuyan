# 帕累托视图实现与验证（2026-09-20）

实现位于 Web 现有排行榜；默认仍为排名，新增可分享的 `?view=pareto` 视图。当前交付为本地实现与预览，尚未部署到线上。

## 数据与范围

- 只使用公开榜单当前 46 个模型及其原有总分、10 个评分维度和详情路由。
- `sourceful/riverflow-v2-pro` 与 `codex:gpt-image-2` 均不在榜单或价格目录中。
- 官方价格独立保存在 `apps/web/src/data/benchmarkOfficialPrices.json`；不读取历史实际扣费计算成本。
- 复核结果为 28 个可核验报价、1 个独立标注的估算、16 个单价已核实但关键条件不足、1 个直营官方价格待确认。首次暂定的 18 个已重新核对；另补入 10 个 Recraft 准确变体。
- 成本采用固定九题等权：6 道生成与 3 道单源图编辑的完整标准报价合计除以 9。保留原请求条件与输出像素差异，不按成功图片数重新加权，不将失败计为免费。
- 价格适用范围绑定原九题 ID、状态、图像 hash、源图 hash、像素和请求分辨率。产物变化时停止绘图并提示重新核验；评分或评语变化不会改变成本。

完整逐模型来源、API ID、版本、原币单价、公式、费用组成、查询日期及未纳入原因见 [官方价格核对表](./benchmark-pareto-pricing-2026-09-20.md)。

## 页面能力

保留排名页，新增成本散点图、总分及评分维度选择、名称/ID 搜索、供应商筛选、价格上下界、对数/线性刻度、缩放、平移和重置。品牌点与右侧前沿列表联动，悬浮或聚焦显示准确 ID、计价条件、价格来源和日期；沿用模型详情页。

前沿在当前筛选范围内重新计算。成本使用精确有理数，评分使用公开数据的未格式化值；同价、同分、完全重合和缺失评分均有明确处理。同坐标模型合并为可展开标记，标签避免覆盖其他点。缩放只改变视窗。

手机布局堆叠筛选、图表与前沿列表，图表可横向滑动并有提示；详情卡保持在屏幕内。逐模型价格表提供独立横向滚动容器。

## 验证结果

- Web 全量自动化测试：430/430 通过。
- 帕累托专项测试：12/12 通过，覆盖严格支配、完全重合、精度边界、维度切换、筛选、像素计费、汇率、输入费、九题权重、失败题、数据绑定、缺价和估算隔离。
- Web 生产构建通过；保留既有主包体积大于 500 kB 的提示。
- 浏览器验收：31 项通过；全部 11 个分数选项逐一与独立前沿计算结果对照。检查真实公开榜单、筛选联动、缺价不入图、详情跳转及返回、缩放、390 px 手机和 768 px 平板布局。
- 浏览器脚本异常、控制台错误、失败请求均为 0。实际查看桌面图表、计价卡与手机截图。
- 本地 API 代理只允许四个公开只读 benchmark action；浏览器实际只调用了 `benchmarkLeaderboard` 和 `benchmarkModelProfile`。没有模型生成/推理入口调用。
- 开发前后再次读取公开榜单，46 个模型的完整数据规范化 SHA-256 相同：`1a022fc48a73250c21772f00cac05ff796dc184b2a12659f08fcb64fccf8d34d`。评分、评语、原图证据、历史费用未变。
- 公开 releaseHash 保持 `8e6619b57c6979d9c5687893afa64fa40a81b5976f49d1466506d3b4a9ddd2fc`。
