# 小程序账户设置文案与对齐修正设计

## 目标

根据微信开发者工具中的实际界面反馈，修正账户设置弹层的三个可见问题：退出按钮文字严格居中；密码输入提示不展示最大长度；修改密码说明明确告诉用户操作和结果。

## 范围

- 保留当前密码和新密码的底层 `8–128` 位校验与 `maxlength="128"`，只隐藏界面中的“128 位”提示。
- 当前密码提示改为“输入当前密码”；新密码提示改为“设置新密码（至少 8 位）”；确认框保持“再次输入新密码”。
- 修改密码说明改为“输入当前密码并设置新密码。修改成功后，其他设备需要重新登录。”
- 退出按钮使用与主要操作按钮一致的 flex 居中规则，不调整退出行为。

## 验收

- 契约测试明确拒绝账户设置可见文案中的 `128 位`，同时继续断言 `maxlength="128"`。
- 退出按钮样式包含 `display:flex`、`align-items:center`、`justify-content:center`。
- TypeScript 检查、构建和全部小程序测试通过；在常见手机宽度重新截图确认。
