# 图研统一账号与多种登录方式

范围：保留 Better Auth 1.6.11 的邮箱注册、显式邮箱验证、密码重置和会话。在同一个运行时添加身份插件；不替换现有认证服务、不迁移内部用户 ID。独立分支基于 f565b75，不包含待合并 PR #183。

身份不变量：业务只认不可变 user ID。邮箱 credential、github、google 都映射同一用户；provider+subject 唯一。OAuth 邮箱仅作冲突检查和第三方资料，不自动成为已验证邮箱，不自动合并。没有邮箱的账号使用随机内部占位值满足既有库约束，客户端和业务展示隐藏它；绑定邮箱后显式验证码确认并设置密码，才成为邮箱登录方式。

安全与生命周期：绑定/解绑前通过现有密码或第三方授权复验，生成 5 分钟、绑定 user/session/purpose 的一次性凭证。无密码注销使用 delete 用途凭证；原邮箱密码删除请求继续兼容。第三方 ID 的唯一约束、最后一种可用方式检查与凭证消费放入 Mongo 事务，事务写用户版本以避免并发解绑和注销竞争。删除清理身份、挑战、授权状态、复验凭证，并记录短期身份注销屏障，拒绝注销前发起的邮箱绑定验证码/回调。

OAuth：服务端固定供应商端点，PKCE S256，一次性 state 与 HttpOnly SameSite=Lax 浏览器 cookie 双重绑定；固定前端返回地址，10 分钟过期。Google 用 jose 验证签名、issuer、audience、expiry、nonce、azp；GitHub 每次通过 access token 查询稳定用户 ID。令牌只用于本次取身份，不持久化、不返回客户端。首次授权若邮箱冲突，提示先登录原账号再绑定；已关联 subject 优先识别原身份。

界面：统一邮箱入口及第三方按钮，保留邮箱现有等待页；可见的验证码错误、过期、限流、取消、冲突和服务异常提示。账号设置管理登录方式与独立验证状态。OAuth 返回恢复登录或账号设置；不在 URL 中回传凭据。

同步：更新 SYNC 和配置文档；Web 消费能力声明，小程序继续使用现有邮箱接口，不增加小程序 OAuth 界面、不上传或发布。

验证：单元覆盖配置、签名/令牌校验；一次性 Mongo + 真实 Better Auth + 本地 OAuth/邮件 测试服务覆盖首次/再次登录、绑定/解绑、并发冲突、错误与生命周期；真实浏览器桌面与手机执行完整邮箱回归及新增流程。GitHub/Google 真实授权、生产配置和发布作为独立未验证项。

外部配置：GitHub/Google client ID/secret、各自回调白名单与 consent 配置；邮箱绑定验证码复用现有 DirectMail。用户已取消手机号与短信功能，本轮不加入短信依赖、配置、入口或付费调用。不在文档中存任何真实密钥。
