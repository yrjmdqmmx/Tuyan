# 生成设置与目录选择

以 c05e340 的已发布通用 API 为基线。保留生成、恢复、密钥地址绑定和用户输入；本轮仅模拟与只读验证，不调用付费生成。

1. 将目录读取和推理配置拆分：连接级校验不依赖型号和能力；目录规则按已核验官方地址或显式兼容规则选择，未知服务默认手动。保持安全网络、逐条隔离、受限分页、脱敏中文错误。记录官方接口及核验日期，同步共享契约。
2. 设置抽屉使用三行等宽模式卡片；统一角色卡片、按钮、折叠和状态样式。空表单用中性引导，失焦/主动校验后再提示缺少能力；能力匹配不依赖 Key。
3. 添加每角色获取/刷新目录、搜索、显式选择及手动 ID；目录可见与配置有效、真实调用分别表示。连接/凭据变更与请求序号隔离晚到响应；刷新保留输入和已选型号。
4. 针对性模拟测试及现有关键回归，真实 Chrome 桌面/窄屏/缩放检查和前后截图，独立规格与质量审阅。按已有授权发布并记录确切部署状态与未验证范围。
