# 使用自有 API 服务

在「生成设置 → 使用模式」选择「通用 API」。普通模式和专业模式的原配置独立保留；切换模式不会替换论文输入。

1. 为主模型、识图模型、图像模型选择实际 API 协议，填写该服务的 Key 和准确模型 ID。主模型负责规划等文本步骤，识图模型负责图片理解和评审，图像模型负责生成和直接精修。
2. 官方服务采用协议默认地址。第三方网关在「接入地址与兼容选项」填写 **Base URL**，包含版本与网关前缀，例如 `https://gateway.example/api/v1`；不要追加 `/chat/completions` 等操作路径。切换地址/协议/认证会清除该角色原 Key，型号及论文输入保留。
3. 同一服务可用「复制主模型接入与密钥」复用连接；每个角色的准确型号及能力仍独立填写。精确匹配已有官方审计配置时可直接使用，其他型号需展开「能力与限额」按服务文档补充并确认。初始限额只是草稿，不是对服务能力的保证。生图/精修还需填写可用比例与分辨率的接口尺寸映射。
4. 「检查配置与地址」只检查配置与公网 DNS；「只读检查模型目录」只读取目录。两者均不代表真实推理可用，不会发送生成请求。无目录的协议可以手填 ID。
5. 选择该配置支持的画面比例、分辨率和生成流程，再主动提交。检索和上传图片受同一阶段预算约束；能力不够会说明原因，不切换渠道或型号。保存非敏感配置不保存 Key，刷新后须重新填写。

若服务拒绝密钥、余额不足或限流，按中文提示在服务商处处理后，可以从原任务已完成步骤继续。需换 Key 时，在同一地址/协议下填写新 Key；其他角色未重新填写的 Key 保留在该任务的加密快照中。任务完成后删除快照凭据，最长保留 7 天。请求结果未知时停止重试，先核对服务商记录与费用。

首版仅 Web 提供接入配置。小程序能查看和恢复已有任务，但更换 Key、修改接入或新建自定义任务请使用 Web。异步任务、OAuth/SigV4、私网地址及厂商任意自定义字段暂不支持。完整适配状态与官方核验日期见 [协议矩阵](protocol-matrix.md)。
