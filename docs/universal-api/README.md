# 使用自有 API 服务

已发布 v3.8.1 在「生成设置 → 专业模式 → 对应模型卡 → 通用 API」中配置三个角色。通用 API 位于渠道列表首位，首次默认仍为 TokenDance；主模型、视觉模型和图像模型可混用不同渠道。

完整配置优化、思考参数、云接口与任务恢复已于 **2026-09-28 作为 v3.8.1 附加更新上线**，见[发布记录](../releases/2026-09-28-tuyan-v3.8.1-supplement.md)与[实现、迁移及官方核查](2026-09-27/implementation.md)。

1. 选择轻量连接模板，填写当前服务 Key 和准确模型 ID。自定义服务可展开连接详情指定协议、HTTPS Base URL、鉴权与目录规则。切换协议保留用户输入地址；绑定变化清除当前角色 Key 并说明原因。
2. 已命名连接保存非敏感连接事实，显式应用到当前角色；更新条目不会改写其他角色的副本。连接复制可以明确选择是否携带当前页 Key。
3. 目录可以跳过，随时手动填写 ID。目录为空、不完整或获取失败都不代表型号退役；状态旁提供修复入口。可信目录元数据展示来源与时间，采用前可与现有声明对照。
4. 已有精确审计可直接提供能力及准确尺寸组合。其他服务按文档确认能力；服务方限制允许未知，图研硬上限不能提高，用户可以设更严格限制。图片编辑不从“能看图”推导。
5. 有精确参数契约的连接显示现有思考控件；默认省略字段，未知型号不出现通用开关。思考偏好按完整身份自动保存在浏览器，不含 Key。
6. 表单即时编辑当前页草稿；「返回生成设置」只关闭弹框。外层「保存到此浏览器（不含密钥）」保存角色和非敏感草稿。连接条目与思考偏好分别明示持久状态。
7. 无密钥配置文件只导出当前角色、适用思考偏好与连接列表；导入先预览，能力声明需重新确认，不执行上游请求。目录验证和真实调用成功状态不能随文件导入。

配置结构、地址安全检查、只读目录和真实调用四种状态分开显示。Key 已填写不等于已验证；检查配置与目录不会发送生成请求。页面 Key 不持久化；已有任务恢复凭据继续服务端加密、完成后删除、最长保留 7 天。结果未知时先核对渠道记录，不自动重发。

Web 响应式界面不代表微信原生界面同步。小程序共享类型可读已有任务，通用配置编辑/更换接入仍使用 Web。既有异步渠道复用原任务查询和下载恢复；通用 API 不提供任意异步 schema。OAuth 自动授权/令牌刷新、AWS SigV4、私网地址、任意 JSON 透传和 cURL 解析未接入。

Responses 图像工具属于当前图像连接，独立配置调用模型、已支持的工具图像型号及当前角色 Key。Azure 使用实际资源地址与部署名，仍需该资源的精确出口授权；Bedrock 仅开放已审计地域和型号。短期凭据需填写实际到期时间，刷新凭据后可主动恢复原任务，不自动申请云权限或重发未知调用。目录/模板和代码已上线，不表示真实账号调用已经验证。
