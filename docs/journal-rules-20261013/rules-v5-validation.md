## 实际黑白内容检查

- 对《山西财经大学学报》正文图规则，解码实际 PNG、转换显示色域后逐像素比较 RGB 通道，完全透明像素不算可见彩色。RGB 容器中的灰色像素可以通过无彩色检查；RGB 头本身不决定结果。
- 反例覆盖彩色图、各通道直方图相同但逐像素有颜色、透明彩色像素、灰度 PNG。彩色图保留原字节，报告 `unmet`，不自动去色、不增像素、不改研究数据。
- 单独文件环境若可解码 TIFF，则检查实际 TIFF 像素；当前 Core 环境受限，因此 TIFF 黑白状态为 `uncheckable`，同一任务 PNG 可报告 `unmet`。这不是矛盾，而是检查能力不同。
