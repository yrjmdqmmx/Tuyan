# iOS UI 与实际使用验收清单

> 用户完成 Internal TestFlight 安装后的真实 UI 与实际使用验收并明确确认前，**不得提交 App Review**。本清单不触发 App Store Connect、TestFlight 或任何付费模型调用。

## 安装与五个工作区

- [ ] 从 Internal TestFlight 安装候选构建；确认版本号、启动、升级覆盖与退出重开正常。
- [ ] 依次检查 Generate、Refine、Records、Guide、Settings 五个 Tab：顺序、图标、选中态、安全区、触控范围和无截断文案。
- [ ] 在浅色、深色和较大动态字体下重复五个 Tab 的首屏检查；开启 Reduce Motion 后确认状态变化不依赖动画。

## Generate

- [ ] 打开“生成设置”，确认普通/专业模式、服务渠道、三条路由、模型、格式、比例、清晰度与专业流程均来自当前权威 registry。
- [ ] 填写 BYOK Key（仅使用最小权限测试 Key），确认 Key 不在页面、记录、截图或错误提示中回显；Ark 图像探测须单独勾选费用确认。
- [ ] 修改模板字段后浏览精选模板：取消替换会回到模板库，确认替换会覆盖方法、图注和负向提示词。
- [ ] 在手动参考模式打开参考图库，检查搜索、筛选、翻页、选择计数；验证本地上传与图库参考的互斥提示。
- [ ] 用本地图片完成上传、确认与必要时中止流程；不得把任意 URL 当作可提交参考图。
- [ ] 分别检查普通和专业 routes 的提交前禁用原因；仅在预算与权限已批准时做一次最小生成 smoke。

## Result、Refine 与 Records

- [ ] 生成后确认结果图、objectKey/签名预览、PNG 显示、分享导出与任务参数可见；不要把预览截图代替真实生成验收。
- [ ] 从当前结果或本人 Records 进入 Refine，确认源图、精修说明、路线、比例、清晰度和提交面板；任意链接/相册不能绕过来源限制。
- [ ] 在 Records 核对账号记录、本机缓存、详情、阶段、失败反馈和返回导航；确认任务来源显示为 iOS。

## Settings、隐私与预算

- [ ] 打开隐私政策、服务条款、网站、GitHub 和作者二维码入口；确认外链前可见且不含密钥或真实测试邮箱。
- [ ] 核对账号退出与删除账号的确认、密码重输、本地记录/模板清理和隐私文案。
- [ ] 记录本次最小 smoke 的 provider、模型、时间、结果与成本；超出已批准预算时停止，不以目录存在宣称账号权益或调用成功。
