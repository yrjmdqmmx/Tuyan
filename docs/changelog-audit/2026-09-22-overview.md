# 更新日志汇总视图

本轮在 `258e394` 的已发布历史数据上增加汇总和分类切换。公开 JSON 未修改；日期、来源、版本归属与发布状态沿用原核对结果。本轮仅本地实现与验证，无部署。

## 展示与数据

- 入口固定顺序：更新日志、图研工作台、Tuyan Benchmark、OpenAcad、生态事件。默认选中更新日志，选中项同时有填充样式与 `aria-current`。
- `groupPublishedUpdates` 直接复用现有公开产品／事件筛选器。当前汇总为 25 条记录、18 个日期组，按 ISO 日期倒序排列；同日保留每个产品原版本顺序，再列生态事件，不推测同日精确时间。
- 产品使用 `release.date`，事件使用 `date`。未发布、逐条状态未完成或缺有效发布日期的记录不会进入汇总或分类，不以公告日期代填。
- 汇总保留产品独立版本号、类别、发布端与完整更新内容；生态事件按日期、类别和名称展示，生态分类保留原详细内容。没有第二份条目数据源。
- 分类分别显示原 12 / 5 / 4 个产品版本及 4 项生态事件。仅挂载当前视图，避免同一条目出现重复 ID。五个入口支持鼠标、原生链接键盘操作及手机点击。
- 分类片段可分享并在刷新或浏览器前进后退时恢复。已有条目及别名锚点仍定位到公开记录，未发布条目不转到其他产品版本。
- 纯 Web UI 与展示辅助逻辑，没有变更跨端 API、模型目录或任务契约；依 AGENTS.md 不新增 SYNC 共享契约条目。

## 验收范围

专项测试覆盖日期排序、同日归并、全量记录唯一性、完整版本身份、新增数据自动进入两类视图、默认选择、分类隔离与选中状态、历史链接，以及旧发布数据和来源安全校验。

Chrome / Playwright 在桌面 1440px、手机模拟 390px / 320px 检查：三个直接路由及刷新、五个入口顺序、25 条记录与所有产品正文逐项对照、三个同日分组（09-07、09-04、05-14）、分类切换和记录数量、前进后退、分类刷新、旧链接、共享顶部导航与移动“更多”。页面错误、外部请求和 POST 请求均为 0，所有视口无横向溢出。Browser plugin 未提供，沿用前端测试技能的 Playwright 回退路径。

截图与检查清单保存于本轮 `tuyan-changelog-overview` 本地验收目录：`desktop-overview.png`、四个分类截图、320px / 390px 汇总／Benchmark／更多截图及 `checks.json`。已实际查看桌面汇总、320px 汇总和390px Benchmark截图。Safari、微信实体设备及生产页面不在本轮验收范围。

旧组件断言原先要求全页没有“更新日志”链接，以及发布日期位于每条记录内；新汇总入口和日期分组使这些断言不再适用。已改为分别检查顶部导航与分类链接，以及对应日期组的时间元素，保留原功能断言和完整性检查。

最终验证：专项 37/37、完整 Web 510/510，0 失败／跳过；生产构建通过。更新日志独立 chunk 约 44.55 kB，既有主应用 chunk 体积提示仍存在。`git diff --check` 通过；公开数据 JSON 与本轮基线完全相同。
