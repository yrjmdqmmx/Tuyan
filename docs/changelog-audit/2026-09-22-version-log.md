## Tuyan

### Tuyan v3.8.0

2026-09-22 · 已发布 · Web

扩展官方模型渠道，提供按角色保存的思考设置，整理共享导航和中英文切换，并新增按产品独立版本浏览的更新日志。

2026-09-23 追加模型更新；本版本原发布日期为 2026-09-22。

**新增**

- 通用 API 接入：可为主模型、识图和图像模型分别选择已适配的协议、地址与准确型号，支持目录搜索、选择和手动填写。
- 主模型、图像模型和参考图识别模型下方分别提供已核实的思考开关、强度或预算；独立保存设置，“默认”不显式发送思考参数。
- 接入商汤 SenseNova、阶跃星辰、百度千帆、讯飞星辰 MaaS、美团 LongCat，并补齐 Grok 4.7 等准确型号；各角色和限制按接口分别标明。
- 新增 GPT-6 Sol、GPT-6 Luna 和 Claude Opus 5.5，支持主模型规划与参考图识别；OpenRouter 同步接入已核实的普通及 Pro 路由。
- 精修按型号支持辅助参考图、遮罩和结构化修改目标，提交前提示图片数量、尺寸及编辑能力限制。
- 新增更新日志汇总视图，按日期倒序合并各产品已发布更新；支持单独查看 Tuyan、Tuyan Benchmark、OpenAcad 版本及生态事件。

**优化**

- 补齐腾讯 TokenHub、小米 MiMo、Runware 的模型目录；显示具体版本、滚动别名和调用 ID，渠道按国内聚合、国内直连、国外直连、国外聚合排列。
- MiniMax 接入渠道统一显示为“稀宇科技”，保留 MiniMax 品牌与搜索别名，以及已有配置和任务记录。
- 手机工作台按输入、设置、生成和结果组织，模板支持横向浏览；设置控件、模型目录选择和空配置提示更清晰。
- 统一顶部品牌与导航分组，保持工作台、排行榜和 openacad 的顺序及当前页选中状态；手机将页面和辅助入口归入分类“更多”菜单。
- 工作台、排行榜和更新日志共用中英文偏好，页面切换时保持语言一致；移动端语言按钮始终位于顶部。

**修复**

- 参考图按相关性及当前模型预算选择；失败提示说明步骤、原因与费用状态。恢复任务复用已完成步骤，未知提交不自动重发。
- 目录中单条异常不再拖垮整个渠道；刷新或切换后保留已有选择，防止旧请求覆盖新配置。确认不可用的型号从可选列表隐藏，历史记录仍保留。
- 修复仅文本渠道从专业模式返回普通模式，以及尚未填完整的通用 API 配置引起的页面空白；保留原有完整预设和可继续编辑的草稿。
