## 记录规则

- **公告日期**：保留用户提供原稿中的日期，不自动改成提交或部署日期。
- **已核实部署日期**：来自关联部署工作流及既有发布记录；日期统一为北京时间。某版汇总了多次部署时明确写出，不杜撰统一上线时间。
- **代码完成**：只能说明对应功能在某提交存在；不能推定当时已上线，更不能证明所有客户端已发布。
- **已发布**：至少有该功能相关成功部署记录。它不是“所有模型均已实测”或“所有支付/账户流程均已验收”的同义词。
- **版本归属**：这 12 个语义版本号沿用公告。没有发现对应的工作台语义版本 Git 标签，不能把目录 v12/v14/v15 等内部版本当成工作台版本，也不能把文档补记 SHA 当成实际运行 SHA。
- **早期未知**：当前仓库最早提交是 2026-05-17 的 `cc3412e`。5 月 14 日的版本不因后来的迁入快照而自动获得首发部署证据。

## 可供页面消费的数据

历史数据草稿包含 12 条、版本降序，字段为 `version / announcementDate / releaseDate / releaseStatus / title / summary / changes / notes / sources`。每条 change 都有 `sourceIds`：

- 可公开来源限真实 GitHub commit / PR / Actions / 仓库发布文档；不暴露私人工件、授权参数、账户信息或内部地址。

这份数据是公告内容与历史证据的审计输入，最终主产品版本编排仍应由统一 changelog 维护器复核。
