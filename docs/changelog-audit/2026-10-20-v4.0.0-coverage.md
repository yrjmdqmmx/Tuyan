## 过期说法与未纳入项

- 旧文档里尚未发布的阶段状态，须与后续集成、发布和验收链结合判断；反之，代码存在也不证明所有入口都启用了该能力。
- 不承诺多任务或候选真正同时生成。已复核的运行配置为全局执行 1、排队 2、每账号 1、每 IP 1、候选并发 1；同账号第二个执行先触发账号限制。公开文案只说多任务管理和按容量处理。
- 不将 1,103 条静态渠道型号身份称为 1,103 个独立基础模型，不将目录审计、HTTP 路由检查或测试通过称为真实模型质量通过。
- 不使用早期“8 文档/3 图片”“原件云端保留 30 天”“末轮追加隐藏终审”“SVG 不支持曲线节点”等已被最终实现替代的说明。
- 原件本地保存与账号任务同步分开，不能写成跨设备原件云盘。PNG→TIFF 不增加像素细节，且不扩张到未开放该入口的新工作区。
- 取消的独立论文画布实验、尚未进入发布祖先链的本地 TokenDance 长流修改、本次独立模型选择 UI 工作树修改、小程序未正式发布部分均不纳入。
- 本次完整性复核阶段只更新日志与审计，未发起部署、真实模型调用或任务删除。验证结果见主审计文档，不将历史真实调用重复执行；后续日志发布另留回执。
