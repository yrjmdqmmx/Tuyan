| 原实现冲突 | 本轮处理 |
| --- | --- |
| 数据图按类型路由程序绘图，强制专属数据/参数表单 | 新路径取消该路由和表单；材料由主模型读取；图型规范继续用于检索、规划、生成和评审 |

## 实际执行顺序

1. Web 解析文档/表格为可读文字；原始字节 SHA-256、格式、文件名、读取范围和警告随材料保存。图片沿用归属验证、上传完成确认、尺寸/数量校验，原图作为真实像素输入。
2. 用户手选的 none/auto/random/manual 原样进入 Core。自动检索先按图型和结构筛选，再结合主题等偏好；手选和随机遵循各自规则。上传文件不会覆盖模式或手选 ID。
3. 主模型具备视觉能力且视觉设置为“无”时直接读图；选择辅助视觉时，视觉模型读取实际图片，主模型使用观察报告。用户图片和图库图片使用独立的观察预算，图库内容只用于结构/风格。
4. 主模型收到完整材料、图片或观察报告、图库说明及图型合同，返回 ready + 完整方案，或 needs_input + 具体缺项。后者在绘制前停止，不生成缺失数据；规划已有调用不能当作未计费。
5. PNG 把完整方案、图型约束、参考要求及材料摘要交给生图模型；完整原始文档保留在主模型规划和评审侧。图片 API 有提示词限额时明确报错，不静默截断。SVG 则由主模型产出源码，经严格 SVG 校验和实际栅格化后保存。
6. 主模型对照完整材料评审实际画面，或使用辅助视觉对当前版本的观察；SVG 同时提供完整源码。版本、SVG/PNG hash、实际送审图片 hash 随评审保存。修改后重新评审，不能沿用旧版通过结论。
7. 数值正确性属于需要对照材料检查的质量要求；**新模型路径不提供原程序图的数值正确性证书**。未知统计结果、显著性和未提供的结论不能由模型编造。需要尚未计算的分析时会要求补齐材料；没有自动科学计算服务的承诺。

## 本次实际支持的输入

| 格式 | 读取内容 | 明确限制 |
| --- | --- | --- |
| PNG / JPG / JPEG / WebP / SVG | 原图片送主模型或辅助视觉读取 | 平台最多 3 张，每张 5 MiB；仍校验渠道更小的图片预算/尺寸；SVG 沿用安全图片上传约束 |
| TXT / MD | UTF-8 原始文字 | 非 UTF-8、空白/二进制、超限明确拒绝 |
| CSV / TSV | 原始文本、列/行和数值保留 | 校验引号闭合，不猜测缺值、单位或统计计算 |
| JSON | 完整 JSON 文本 | 无效 JSON 拒绝，不执行内容 |
| XLSX | 工作表名、单元格地址与原始值、已有公式缓存 | 最多 12 表 / 2 万单元格；公式缺缓存拒绝；不重新计算；图表/图片/格式/合并布局未读；日期可能是序列值，界面提示 |
| DOCX | 正文和表格行列 | 页眉页脚、批注、修订、公式对象、嵌图未完整读取，作为部分读取提示 |
| PDF | 文字层，逐页标记 | 最多 30 页；扫描/无文字页明确拒绝，提示转图片或 OCR；插图和表格布局未读，提示另传图片或原表格 |

文档最多 8 份，每份 10 MiB、解析后 6 万字符，合计 10 万字符/450 KB。Office 解压内容最多 20 MiB。超限停止并提示，不偷偷裁掉材料。原二进制文档只在浏览器解析；任务保存的是提取结果和原文件摘要，**不是一个原文件云盘**。未提交文档不持久化到浏览器存储；退出账号清理当前材料。
