# 信息图分类与参考库规范（实施基线）

日期：2026-10-10。工作树 `codex/tuyan-v400-workflow-20261009`，基础提交 `5e6989f`；开工文件 hash 在 `evidence/baseline.json`。本轮不部署、不操作小程序；既有 SVG 真实渲染与版本评审语义保留。

## 已核实的问题

旧八类同时包含大类、基础图型、表达目的。Web 发送中文名称，Core 检索只接收 diagram/plot；PNG 绘制依赖中间方案保留类别，类型知识库检查项未接入运行。统计图把自由文本当数据，无确定性数值门禁。旧 PaperBananaBench 306 个素材只有数据集来源声明，缺少逐图授权记录。

## 研究依据与维度

- Brehmer & Munzner (2013), [Multi-Level Typology](https://www.cs.ubc.ca/labs/imager/tr/2013/MultiLevelTaskTypology/)：任务目的、方法、输入输出分开。本项目不复制其受限许可图像。
- [Vega-Lite marks](https://vega.github.io/vega-lite/docs/mark.html)、[boxplot](https://vega.github.io/vega-lite/docs/boxplot.html)：图元、复合图元、编码参数并非同一层级；箱线须说明须线算法。
- [SBGN specifications](https://sbgn.github.io/specifications)：过程描述、实体关系、活动流是不同语义，不能因都有节点和箭头而归并。
- OpenAcad 当前本地 `docs/acceptance/templates.csv` 的 55 个模板仅作为候选。分组、误差、环形布局归变体；PCA/PCoA/NMDS/CCA/RDA 作为排序图的分析方法配置，各自保留必要输入和校验，不能互换科学含义。
- 真实论文 XML、图注和图像另存 `evidence/papers`，逐图边界判断写入案例清单，不能以模板模拟数据代替论文案例。

六个分离维度：表达目的（比较/关系/分布等）、基础图型（稳定 ID）、变体（不增加基础图型计数）、分析方法（输入/计算要求）、学科标签、组合方式/子图清单。浏览大类仅是导航，不能提交为具体图型；历史 data_stat 保留历史含义，新建须选择具体类型。

## 方案取舍

1. 扩展旧常量和短提示词：改动少，但分类、图库和评审仍会漂移，淘汰。
2. 接入整个 OpenAcad 渲染应用：能够复用较多专业分析，但引入另一个产品的数据/后端契约，超出本轮且不能处理示意图，淘汰。
3. **采用共享分类注册表＋结构化规范＋阶段适配器**。新包独立于 UI；Web、Core、知识入口从同一数据读取。数字图使用数据门禁和程序验证，领域专用能力按实测状态公开，不把提示词接通等同专业正确性通过。

## 运行契约

`figureTypeId`、`figureVariantIds`、`figureAnalysis`、`figurePanels`、`figureData` 为可选兼容字段；后端根据注册表解析真实类型/路线，不信任客户端传入的规范。旧 infographicCategory 和旧任务保留，别名仅用于解析/搜索。规范含定义、适用/不适用、输入、元素、编码、变体、易混淆、案例、生成/检查清单。原始要求和规范独立传给检索、主模型、绘制和评审，避免依赖模型复述。

检索先许可门禁，再精确类型/明确兼容类型，再主题/学科/密度/布局排序。不同分析语义不自动互换；记录匹配等级和原因；没有可用素材返回空结果。人工选图同样经过权限门禁，不能绕过。

主模型负责内容整理、完整方案和修订决定；生图模型只执行示意图绘制约束；程序化绘图负责真实数据编码。数值检查与视觉评审分别记录，未进行程序核验的结果不能标成科学正确性已验证。缺数据/单位/统计定义先报缺失，不用模型补数。组合图必须列出子图类型，子图继续执行自己的数据要求。

## 参考使用许可

[PLOS policy](https://journals.plos.org/plosbiology/s/licenses-and-copyright) 与 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/legalcode.en) 仅为规则依据，不能代替每图检查。逐图保留原始文件/完整图注/论文作者和期刊年份/DOI/图号/许可正文和链接/第三方例外检索/署名/修改记录/hash。分别记录存储、展示、作为模型输入复制、改编的许可判断及前提。模型输入不额外授予训练、肖像、商标或隐私权；应用仅按已确认复制/改编权提交并保留出处。含未澄清第三方图片的整张组合图待核验，不凭文章级 CC BY 放行。

既有素材不删除历史记录，未知许可从新任务的正式可用池隔离。实际图库数量和类型覆盖由核验结果决定，空缺明确显示。原论文数据与结论不得迁移到新研究。

## UI 与验收

生成设置内显示完整路径。选择器：大类导航＋具体图型卡片＋按需详情；中文/英文/别名搜索直接定位具体图型，键盘焦点、关闭返回、窄屏单列。图库复用同一大类/图型，展示授权和可参考设计，统计暂无合格案例。

验证包含迁移/保存、搜索/导航/移动端键盘、许可阻断、精确与兼容匹配、无匹配、每阶段实际请求约束、数据缺失/单位/范围/统计定义错误、不同图型的渲染与评审区别、SVG 版本语义回归。计数分开：基础图型、变体、许可核验案例、流程支持、程序验证、真实模型效果，不混合。
