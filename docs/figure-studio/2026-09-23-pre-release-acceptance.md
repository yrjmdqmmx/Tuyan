## 代码与集成完成情况

- 复用账号会话、模型目录、渠道路由、通用 API 连接与公共调用/恢复引擎；画布维护自身结构规划、对象命令和版本绑定。原生渠道恢复使用原提交加密凭据；替换当前配置密钥恢复仅支持通用 API，不承诺原生渠道可在原操作中换钥匙。
- 规划和语言编辑携带当前图稿，服务端生成官方基线与工作规则上下文；请求绑定图稿完整 SHA-256 和规则上下文 SHA-256。提交、执行、恢复及结果确认分别校验，旧成功记录仍可查询。
- 真实联调发现 Gateway 丢失规划 `document` 和 `generationContextSha256`，已修白名单透传，并增加 Gateway 独立的 `generationContextTransportVersion` 确认。Web 同时检查 Core 与 Gateway 契约版本；不得仅凭 Core 声称支持就发送请求。
- 模型等待默认由 45 秒调整到 180 秒，保留持久操作查询和不自动重发原则。超时或未知结果不等于未计费。Runware 已知任务 UUID 的恢复只查询原任务；未知结果在 UI 中保守阻止恢复。
- 加入跨标签页自动保存冲突保护，旧标签页不会静默覆盖新源稿；可以先下载本页备份，再明确载入浏览器中的已保存稿。
- SVG 检查实际 XML 的尺寸、文字与独立对象；PDF 检查实际页面树、文字指令、嵌入字体流；EPS 检查实际 DSC 边界声明。人工项及不支持的解析情形保持“需要人工确认”或“尚未核实”。
- Nature 来源、范围和核对日期已更新，官方示例与硬性限制区分；用户工作规则不改变官方核验基线。科学准确性、视觉质量和 AI 政策独立核验，技术通过不等于可投稿。Science 官方页当前访问受限，未发布未经核实的规则预设，见[期刊证据记录](./2026-09-23-journal-evidence.md)。
- 本地 Linux 转换包装脚本修正 macOS `/var` 与 `/private/var` 路径映射，仍使用固定已有镜像、禁止网络和拉取。转换器成功退出却未生成可读文件时，服务端现在返回明确导出错误，不再误报模型渠道异常。

- **Runware 页面恢复仍有保守限制**：后端具备按已保存 UUID 仅轮询原任务的能力，但页面对未知结果统一禁止恢复。该页面路径尚未开放及真实验收；后续需要显式的安全轮询能力标记，不能直接放开所有未知操作。
- **EPS 可靠编辑往返未通过**：本次已观察到文字合并及重开时 α 不显示，文件字节仍保留该字形与绘制指令。需修复后重新逐项验收，或在上线范围中明确将 EPS 定位为带已知限制的交付选项，不能承诺可靠编辑往返。PDF 字体替代、字号及页面舍入差也必须披露，不承诺所有软件无损互通。外部编辑文件重新导入图研仍不在本阶段能力内。
