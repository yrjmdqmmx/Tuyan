# 连接正式账号的本机消费预览

这是面向用户手动操作的真实 TokenDance 接入环境，不使用模拟模型、模拟余额或模拟支付。

启动（Node 24，Docker 已启动，依赖已安装）：

~~~sh
cd apps/paperbanana-api
node --import tsx ../../scripts/tokendance-local.mjs
~~~

访问 http://127.0.0.1:5173/ ，使用现有的正式图研账号登录，再通过“TokenDance 连接与钱包”授权已有的 TokenDance 账号。新注册、邮箱验证和找回密码也由正式账号服务处理；注册与找回密码回调保持已登记的正式站点 URL。用户在页面提交这些操作会产生真实账号操作和相应邮件请求。

正式服务拒绝浏览器从 localhost 直接跨站请求，因此使用仅监听固定 loopback 的本地账号代理。它只接入预先列出的账号接口，先验证本地 Host/Origin，再以图研自身的服务端请求访问固定 HTTPS 正式账号服务；没有修改正式服务器的 CORS/CSRF 白名单，没有复制正式环境管理密钥或数据库凭据。密码只在用户提交时转发，不保存到本地数据库或日志。

浏览器只持有随机、HttpOnly、SameSite=Lax 的本地会话标识；正式账号的 Cookie 保存在 AES-256-GCM 加密的本地记录中，最长 7 天。每个受保护的本地 API 请求都向正式服务器重新确认会话及账号生命周期，禁用上游 Cookie 缓存校验捷径。退出会同步调用服务器退出并删除本地记录；服务器结果不确定时明确返回此状态。正式账号管理与注销入口引导回正式站点。

初始选择 TokenDance、1 张候选图、0 轮评审。用户点击生成、精修、优化输入时会调用真实模型并消耗其 TokenDance 余额；创建充值单使用真实支付接口，付款由用户完成。脚本不会自动授权、调用付费模型、创建订单或付款。产品方管理价目未配置凭据。

本次预览的任务、图片和 TokenDance 渠道授权仍保存在本机，并绑定正式账号不可变 ID；线上历史记录在正式图研查看。TokenDance 新接口尚未发布到正式服务器，不能把这个版本描述成已上线或任务已同步到线上。

Mongo 容器为 tuyan-tokendance-local，使用专属持久卷，只绑定 loopback 随机端口。用户 Key、任务执行凭据和步骤结果由本地运行的完整 Core 服务加密；稳定随机密钥保存在 ~/.config/tuyan-tokendance-local/secrets.json（0600），父目录 0700。图片以本地文件保存，上传/下载 URL 使用限时 HMAC 签名；网关拒绝外来 Origin、错误 Host、匿名 TokenDance 操作和未签名图片读取。完整 Gateway/Core、正式 Better Auth 账号服务和真实 TokenDance 适配器均参与执行。其他渠道的付费调用在该预览运行器中关闭。

Ctrl+C 停止 Web/Gateway/Core，并等待已启动的任务完成；保留 Mongo 容器/卷、图片与加密连接，下次启动可继续使用。不要在有待恢复任务时删除本地密钥文件。此前独立本地账号的数据没有迁移或归属给同名的正式账号。

2026-09-09 验证：账号代理 9 项契约回归通过（上游为测试桩，覆盖加密/重启、身份绑定、原站点回调、限流、失效、注销阻挡、退出并发、空请求体退出、错误和 Origin 边界），Web 367 项及构建通过。真实服务器匿名会话查询返回 200；通过本地代理对一个随机不存在账号做负向登录，服务器返回 401 INVALID_EMAIL_OR_PASSWORD，没有签发本地会话；匿名 TokenDance 操作为 401。桌面页面确认显示正式账号登录说明。未自动创建正式账号、发送用户邮件、交换真实 TokenDance Key、调用模型或付款；这些正向流程由用户登录后继续操作。
