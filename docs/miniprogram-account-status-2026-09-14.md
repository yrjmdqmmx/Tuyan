# 小程序 3.5.1：连接状态与授权文案

延续 `codex/miniprogram-mobile-ui-20260914`，代码提交 `ef53238e24be7410db81e59aeba5558e4ee893e4`。

账户页此前每次显示都会把 `statusLoading` 设为 true，WXML 又优先展示“正在查询”，因此已有连接也被加载文字替换。模型设置的按钮则固定写“账户授权”，没有区分连接状态。

现在账户页先使用当前账号已确认的状态，并后台复核；只有尚未取得状态时才显示查询中。并发状态请求合并为一次，未增加长期缓存，也没有省略服务端复核。查询失败会清除可用状态，显示“连接状态暂无法确认”和“重试查询”；退出、切换账号、解除连接及重新授权都会失效旧状态，晚到响应不能恢复旧连接或覆盖已完成的解除结果。

模型设置中，已连接的观猹角色显示“已连接 · 使用观猹账户额度”和“管理授权”；未连接时才显示“连接账户”。展开的说明明确已连接无需再次授权或填写 Key。原有设置草稿、保存/取消和独立渠道 Key 校验保持，Google 或百炼缺少 Key 不受观猹连接状态影响。

源码类型检查、构建及108/108测试通过；上传副本类型检查与108/108同样通过。新增测试覆盖并发请求、已确认状态、网络失败、A-B-A账号切换、解除后的晚到响应；既有角色测试增加已连接/未连接按钮状态断言。

实际开发工具教程确认版本 `miniprogram-3.5.1`。iPhone 15 Pro Max 中多次往返生成与账户，显示“已连接”；两个观猹角色显示“管理授权”，Google继续显示缺少Key。方法166字、图注23字、原三个模型及PNG/1K/自动比例保留。网络失败、账号切换、解除连接和新授权通过本地可控测试验证，没有对真实账号执行这些操作。点击“管理授权”后显示已连接、无需再次授权或填写Key的说明。最终返回生成页，控制台0错误，剩余提示为灰度基础库及自动热重载。原生截图已在任务中展示。详见 [验证记录](evidence/miniprogram-3.5.1/validation.json)、[源码测试](evidence/miniprogram-3.5.1/source-tests.txt) 与 [副本测试](evidence/miniprogram-3.5.1/upload-tests.txt)。
