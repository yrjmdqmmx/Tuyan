## Pro / Lite、1K / 2K 的根因与处理

最新用户截图以及本次3.3.0初始原生基线均显示 Pro/1K，不能据此断言“仅打开设置就必然切换”。代码确认另一条可复现路径：旧页面初始化对观猹额外选择 Pro，而通用 `providerDefaultRoutes` 仍取目录的 Lite；再次点击当前普通模式/渠道也会重新取默认路由，Lite不支持1K时草稿清晰度被归一到2K。首页继续展示已保存的Pro/1K，因此草稿与摘要可能暂时不同。旧版还没有将这组模型/输出偏好单独持久化。

本次统一客户端观猹默认入口为可选的 `seedream-5.0-pro`；重复选择当前模式/渠道无操作；打开弹层克隆已保存设置；更换模型只归一不兼容的草稿参数并显示说明；保存才整体应用，取消丢弃草稿。明确选择的 Lite/2K 等有效配置会保留，不强制迁回Pro。

新增 create/refine 独立白名单偏好存储，仅模型、输出、流程和区域设置；不保存 API Key、Cookie、身份、提示词或任意未知字段。冷启动使用保存值，缺失/损坏才回退默认。当前模型目录和提交构造器继续校验模型、尺寸与比例。比例组件没有自建模型能力列表。

原生生成与精修的实际页面提交函数均经本地拦截观察为 Pro/1K/16:9，和保存/选择状态一致。回归另外覆盖显式 Lite/2K、取消、重新打开、持久化、切换不兼容尺寸，以及精修设置与内联参数共用状态。

## 交互与兼容性修复

- 弹层打开隐藏原生 tab bar，关闭恢复；flex 滚动区保留最小高度0，安全区只加一次。根据视口是否已被键盘缩小计算剩余 inset，避免双重扣减；凭据聚焦后滚动至输入项。
- 去除 `auth-panel.wxss` 的标签后代选择器，改为类名。为关键按钮提供足够的类选择器优先级，覆盖微信 v2 原生按钮默认宽度、margin 和边框，不依赖不允许的属性选择器。
- 比例组件首次加载提供有效默认值；阶段组件等待 job 就绪后再挂载，消除属性类型警告。
- 冷启动恢复登录时重新刷新消费授权状态，避免登录已完成但当前工作区仍视为不可用。
- 生成提交消除重复 hideLoading；精修新提交清除旧任务ID，避免新失败被旧任务区域遮住。
- 明确移除精修原图后，页面往返不再自动补选历史第一张图。现有上传校验、原图保留、输入优化、任务恢复和账户生命周期代码继续使用。
