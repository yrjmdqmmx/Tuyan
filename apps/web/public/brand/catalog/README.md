# Model catalogue brand assets

These files are served locally for identification in the Web model picker.
The adjacent model-brand-logos metadata in `src/data/model-brand-logos.json`
records the original URL, SHA-256, and asset license/source for each brand.

LobeHub SVG assets: @lobehub/icons-static-svg 1.95.1, MIT.
See LICENSE-lobe-icons.txt and https://github.com/lobehub/lobe-icons.
Other files were obtained from the brand's public website, documentation,
or official model organization profile. The respective brand owners retain
their trademark and artwork rights. Inclusion identifies a provider/developer
and does not imply endorsement or an account's access to its services.
