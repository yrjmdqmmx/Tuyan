# 图型认识预览

这些资产仅用于信息图选择器，不是用户任务数据或生成质量证据。

- 分类规范：`packages/figure-taxonomy/src/index.js` 中的稳定具体图型 ID。
- 论文来源：`packages/figure-taxonomy/src/references.js` 中已逐图核验的参考记录。
- 人工选图：`type-preview-sources.mjs`。每个图型明确参考 ID、面板、裁剪范围和一句结构说明；不能按论文主题自动填图。
- 教学替代：`build-type-previews.mjs` 的逐图型结构绘制。仅在没有合适论文预览时使用，页面标记结构示例或模拟数据。
- 输出：`apps/web/src/data/figure-type-previews.js` 和 `apps/web/public/figure-type-previews/`。

在仓库根目录运行 `node scripts/figures/build-type-previews.mjs` 重建。脚本复用已安装的 API 端 sharp，校验许可可用性、具体图型映射和裁剪边界。缩略图为不超过 960 × 600 的 WebP；完整原图继续指向图库原资产。来源记录、原始图注、署名、许可核验记录、原图哈希、原始尺寸和修改说明一并写入索引。裁剪使用原图百分比 `[左, 上, 宽, 高]`，不得删除解释图型所必需的坐标、图例或分支。

新增分类时必须补充独立预览；新增或替换论文案例须先完成图库许可核验，确认图注的第三方素材例外，再人工检查原图与缩略图。图库具有相同标签不等于适合作为代表预览：旧气泡图和哑铃图的两个候选已记录排除原因并修正图库标签；目前使用新核验的代表案例。路线图、流图、玫瑰图继续保留带原因的结构示例。缺失或加载失败显示明确提示，不能补入无关图片。

预览不修改 taxonomy 的支持状态，不进入参考检索候选池，不把论文中的数值、显著性或结论迁移给用户。选图、查看预览和切换完整原图是独立操作。类型规范的修改必须另行同步检索、规划与绘制。

`apps/web/tests/figure-previews.test.mjs` 检查全目录覆盖、可解码性、体积、来源哈希、许可依据、面板映射、放大不选中、完整上下文、候选状态及缺图提示。图库回顶回归包含在 `rendered-interactions.test.mjs` 中。源图或裁剪变化后还应在桌面、手机检查关键图型差异和长图上下文。
